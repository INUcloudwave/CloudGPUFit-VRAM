# GPU 세대별 cuDNN 표로 합성곱 60개 조건 재평가 (2026-11-26)

- 측정: 같은 측정 스크립트 v3, 형태 4,206개, 1순위 작업 공간 (`probes/`)

| 표 | 측정 GPU | cuDNN / torch | 결과 | 적용한 GPU |
|---|---|---|---|---|
| Ampere | RTX 3090 (INUGPU, 11-23) | 9.1.0 / 2.6.0 | 4,206 ok | 3090, A10G |
| Ada | AWS g6.xlarge L4 (11-26) | 9.1.0 / 2.6.0 | 4,206 ok | L4 (g6, gr6), L40S |
| Turing | AWS g4dn.xlarge T4 (11-26) | 9.1.0 / 2.6.0 | 4,202 ok + 4 skipped_memory | T4 |
| Blackwell | AWS g7e.2xlarge RTX PRO 6000 (11-25) | 9.7.1 / 2.7.1 (cu128) | 4,206 ok | RTX PRO 6000 (g7e), RTX PRO 4500 (g7) |

- 평가: `final_eval_pergpu.py` → `final_eval_pergpu_summary.json` (기존 `final_eval.py`는 그대로)
  - 1단계(CPU 라이브러리 버퍼 제거) + 세대별 표 + cuBLASLt·max_pool 규칙
  - 재시도 없는 조건만 쓴다. g7e는 gpu_profiles에 없어서 용량 = cuda_total_memory로 둔다(이 조건들에는 재시도가 없다).

## 결과 (100 MB 이내 / 바이트 일치 / 오차 범위 MiB)

| GPU | v3 | 1단계 | 3090 표 + 규칙 | **자기 세대 표 + 규칙** |
|---|---|---|---|---|
| RTX 3090 | 41, 17 | 50, 36 | 60, 58, [0, +4] | **60, 58, [0, +4]** |
| A10G | 41, 17 | 50, 36 | 60, 58, [0, +4] | **60, 58, [0, +4]** |
| L4 (g6, gr6) | 46, 14 | 55, 33 | 48, 35, [−766, +1,796] | **60, 58, [0, +4]** |
| L40S | 46, 14 | 55, 33 | 48, 35, [−766, +1,796] | **60, 58, [0, +4]** |
| T4 | 42, 9 | 51, 29 | 60, 40, [−66, +94] | **60, 58, [0, +4]** |
| RTX PRO 4500 (g7) | 37, 10 | 46, 22 | 55, 23, [−960, +40] | **60, 53, [−8, +2]** |
| RTX PRO 6000 (g7e) | 37, 10 | 46, 22 | 55, 23, [−960, +40] | **60, 53, [−8, +2]** |

- **모든 GPU에서 60/60**이다. Ampere·Ada·Turing은 58개, Blackwell은 53개가 바이트 단위로 일치한다.
- 같은 세대의 다른 GPU에도 표가 그대로 통한다.
  - L40S에 L4 표, A10G에 3090 표
  - **g7(RTX PRO 4500)에 g7e(RTX PRO 6000) 표**: g7은 따로 측정하지 않았는데도 60/60이다.
  - g7과 g7e는 60개 조건의 실측 reserved가 서로 같았다.
- 남은 차이는 Blackwell에서 최대 8 MiB다. 반복 측정 변동(최대 4.5%)보다 훨씬 작다.
